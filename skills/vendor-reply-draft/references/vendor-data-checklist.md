# 거래처 방어 근거 데이터 체크리스트

단가 인상 대응 메일을 쓰기 전에 아래 항목을 확인한다. 사용자가 엑셀/CSV/텍스트로 제공하면 그 값만 인용하고, 없는 항목은 초안에 넣지 않는다.

## 최소 확인 항목

| 항목 | 왜 필요한가 |
|---|---|
| 거래처명 | 어느 거래처 건인지 명확히 |
| 대상 품목 | 인상 대상 원육/부자재 특정 |
| 현재 단가 | 인상 전 기준가 |
| 요청된 인상 단가/인상률 | 인상 폭 파악 |
| 직전 인상 시점 및 폭 | "최근에도 올랐는데 또 인상"인지 판단 근거 |
| 최근 12개월 거래 물량 | 협상력(우리가 큰 고객인지) 근거 |
| 계약 형태·만료일 | 장기계약이면 계약서 조항 근거로 인상 시점 지연 요청 가능 |

## 데이터가 없을 때

- 데이터 없이 "인상은 곤란하다"는 식의 근거 없는 거절 초안을 만들지 않는다.
- 사용자에게 "거래 단가 이력이나 최근 발주량 데이터가 있으신가요?"라고 먼저 확인한다.
- 데이터 없이 진행해야 한다면, 초안에 구체적 수치 대신 "당사 거래 규모를 감안하여" 같은 정성적 표현만 쓰고, 사용자가 검토 시 실제 수치로 채워 넣도록 안내한다.

## 예시 입력 형식 (사용자가 이렇게 던져주면 가장 빠르다)

```
거래처: OO축산
품목: 삼겹살 원육
현재 단가: kg당 8,500원
요청 인상가: kg당 9,200원 (8.2% 인상)
직전 인상: 2026년 3월, 5% 인상
최근 12개월 거래량: 연 120톤 (해당 거래처 매출의 약 15% 추정)
계약: 2026년 12월까지 단가 고정 조항 있음
```
