# 거래처 단가 인상 대응 / 메일 초안 (Vendor Reply Draft)

인생푸드가 원육 등 원부자재 단가 인상 통보를 받았을 때, "일단 알겠습니다"로 받아들이지 않고 **우리 쪽 데이터를 근거로 방어**하는 답장 초안을 만드는 스킬이다. 목적은 "정중하게"가 아니라 "정중하면서도 근거 있게 방어하는 것" — 감정적으로 거절하거나 무조건 수용하는 대신, 거래 실적과 계약 조건을 근거로 협상 여지를 만든다. 이 스킬은 **초안만 작성**하며, 실제 발송은 항상 사용자가 직접 한다.

이 스킬은 [news-clipping](../news-clipping/SKILL.md) 스킬이 잡아낸 이슈(예: "원육 가격 상승" 뉴스)가 실제로 거래처의 인상 통보로 이어졌을 때 바로 이어서 쓰는 것을 염두에 두고 설계됐다.

## 절차

### 1단계 — 인상 통보 내용에서 사실관계를 뽑는다

받은 통보(이메일, 공문, 메신저 등)에서 아래를 구분해 정리한다. 원문에 없는 내용은 지어내지 않는다:
- 인상 대상 품목 (예: 삼겹살 원육, 특정 부위)
- 인상률 또는 인상액, 적용 시점
- 인상 사유로 제시된 근거 (원육 시황, 환율, 사료값 등 — 상대가 제시한 것만 기록, 사실 여부 판단은 하지 않음)
- 통보 형식이 협의 요청인지 일방 통보인지

### 2단계 — 우리 쪽 방어 근거 데이터를 확인한다

아래 데이터가 있는지 사용자에게 확인하고, 있으면 반드시 반영한다 (references/vendor-data-checklist.md 참고):
- 해당 거래처와의 **최근 단가 이력** (직전 인상 시점, 인상폭)
- **거래 물량/비중** (연간 발주량, 우리가 그 거래처 매출에서 차지하는 비중 — 협상력의 근거)
- **계약 조건** (장기계약 여부, 가격 조정 조항, 계약 만료일)
- 필요하면 **경쟁 대체 공급처 존재 여부** (실제로 대체 가능한지는 신중히 — 근거 없이 언급하지 않음)

데이터가 없으면 방어 논리 없이 막연히 "인상은 어렵습니다"라는 초안을 쓰지 않는다 — 먼저 사용자에게 데이터를 요청하거나, 데이터 없이 진행할지 확인한다.

### 3단계 — 방어 전략을 정하고 사용자 확인을 받는다

2단계 데이터를 바탕으로 아래 중 어떤 조합으로 대응할지 사용자와 확인한다(references/negotiation-tactics.md에 문구 예시):
1. **인상 근거 자료 요청** — 원육 시세 지수, 원산지 증빙 등 객관적 근거를 먼저 요청
2. **인상 시점 유예** — 계약/예산 주기를 이유로 적용 시점 연기 요청
3. **단계적 인상** — 요청된 인상률을 한 번에 반영하지 않고 분할 적용 제안
4. **물량 기반 협상** — 장기·대량 거래 실적을 근거로 인상폭 완화 요청
5. **대체 공급처 검토 시사** — 관계 훼손 리스크가 있으므로, 실제로 검토 중일 때만 포함하고 사용자 승인 없이 임의로 넣지 않는다

전략이 정해지지 않았으면 임의로 하나를 골라 쓰지 않고, 1~2개 조합을 추천하며 사용자에게 확정을 요청한다.

### 4단계 — 공식체·정중한 톤으로 초안을 작성한다

구조:
1. 제목 — "[품목] 단가 조정 요청 관련 회신"
2. 인사말
3. 통보 확인 — "말씀하신 [품목] 단가 인상 요청 건 확인하였습니다"
4. 본문 — 2~3단계에서 정한 데이터와 전략에 따라 방어 논리 전개 (숫자는 실제 제공된 데이터만 사용)
5. 요청 사항 — 상대에게 필요한 다음 액션(근거 자료 제출, 재협의 일정 등)
6. 마무리 인사 및 서명 자리표시자 ([이름]/[직함]/[회사명])

### 5단계 — 검증 후 제시한다

- 데이터에 없는 숫자·조건이 초안에 들어가지 않았는지 확인한다.
- 전략이 두 가지로 갈릴 수 있으면(예: 강경 대응 vs 관계 유지 우선) 두 버전을 함께 제시하고 사용자가 고르게 한다.
- 결과물은 바로 복사해서 쓸 수 있는 평문 텍스트로 제공한다.

## 그 외 용도: 일반 거래처/경쟁사 메일 답장

단가 인상 대응이 아닌 일반 문의 답장에도 같은 스킬을 쓴다. 이때는 2~3단계(방어 데이터·전략) 대신 아래로 간소화한다:
- 답변 방향(수락/거절/조건부/보류)이 정해져 있는지 확인 → 안 정해졌으면 사용자에게 되묻는다
- 경쟁사 대응 시에는 내부 정보(원가, 실적, 미공개 전략)를 절대 포함하지 않고, references/tone-guide.md의 "경쟁사 대응 시 주의"를 따른다

## 흔한 실수

- **방어 데이터 없이 감으로 협상 논리를 지어냄**: 2단계 데이터 확인 없이 진행하지 않는다.
- **인상 통보를 그대로 수용하는 초안만 씀**: 최소 1개 이상의 방어 전략(3단계)을 검토했는지 확인한다.
- **대체 공급처 언급을 사용자 확인 없이 넣음**: 관계에 미치는 영향이 크므로 반드시 확인 후 포함한다.
- **데이터에 없는 인상률·물량 숫자를 지어냄**: 실제 제공된 숫자만 인용한다.
- **경쟁사 답장에 내부 정보를 흘림**: tone-guide.md의 경쟁사 대응 규칙을 항상 적용한다.
- **바로 발송 가능한 것처럼 재촉함**: 이 스킬은 초안까지만, 발송은 항상 사용자 몫.
